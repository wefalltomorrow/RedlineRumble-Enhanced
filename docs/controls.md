# Camera controls

| Input | Behaviour |
| --- | --- |
| `C` | Switch between original hood view and distant chase view |
| Hold `B` | Look backwards |
| Release `B` | Return to the active forward camera |

In hood view, the rear-facing camera moves behind the vehicle to avoid looking through the car's roof. v36 restores the original forward hood position and resets the rotation when `B` is released.

The camera behaviour was confirmed working by the project tester on v36.
